# Flutter 组件大全速查与学习指南

欢迎来到 **Flutter 组件大全**！

这是一份为 Flutter 开发者精心整理的组件学习与实战速查手册。Flutter 以其“一切皆组件 (Everything is a Widget)”的理念著称，庞大的组件库往往让初学者感到无从下手。

本项目通过核心文档，旨在帮助开发者**理清学习优先级**，并在实际开发中提供**最详尽的属性速查**。



### 📚  Flutter组件大全.md
如果你是一个 Flutter 新手，看着几百个组件不知道从哪里学起，这份文档将是你的“避坑指南”。
我们根据真实开发场景中的**使用频率**，将 250+ 个核心组件划分为了 6 个层级：

*   **🔴 极高频使用 (25个)**：如 `Container`、`Row/Column`、`Text`、`ListView` 等。这些是构建任何 App 的基石，**必须熟练掌握**。
*   **🟠 高频使用 (30个)**：如 `Positioned`、`InkWell`、`FutureBuilder` 等。掌握它们能让你应对绝大多数复杂布局和交互。
*   **🟡 常用 (35个)**：如 `SliverAppBar`、各类表单元素等。
*   **🟢 中等使用 (45个)**：如动画相关的 `AnimatedSwitcher` 等进阶组件。
*   **🔵 较少使用 (55个)**：冷门组件或底层绘制组件，仅在特定场景（如画板、复杂联动）下需要，查阅即可，无需死记。
*   **🍎 Cupertino 系列 (31个)**：专门针对 iOS 视觉风格的独立组件体系。

> **💡 建议**：按此目录的颜色层级自上而下进行学习，切忌一开始就陷入冷门组件的泥潭。
